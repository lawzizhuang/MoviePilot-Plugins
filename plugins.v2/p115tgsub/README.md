# 115 TG 订阅追更（P115TGSub）

MoviePilot V2 插件：读取 MoviePilot 待处理订阅（状态 `N`、`R`），直接检索 Telegram 公开频道中的 **115 与夸克** 分享资源，校验分享目录与缺集后转存缺失的电影和剧集；夸克转存成功后联动 SmartStrm 在本地增量生成 STRM。

## v2.2 能力

- **115 离线下载**：支持 Telegram 公开消息正文直接包含的 ED2K / 磁力链接；提交时显式传入电影或电视剧季目录的 115 CID，不使用默认离线下载目录。
- **完成确认与兜底抑制**：提交成功仅进入待确认队列；目标目录出现匹配媒体文件后才更新订阅。下载中的电影或剧集不会进入夸克重复兜底，任务超时后自动释放。
- **范围边界**：仅处理 Telegram 正文直链；不抓取 SeedHub、sidhub.cc 或其他第三方资源页，不支持 `.torrent` 文件。

## v2.1 能力

- **夸克目录分页保护**：分享目录返回空页时立即停止分页，避免异常总数导致持续翻页阻塞同步。
- **脱敏失败分类**：夸克候选失败区分分享失效、访问码异常、访问受限、风控、网络或接口异常；不记录分享链接、访问码或响应原文。
- **运行状态卡**：详情页展示最近一轮订阅处理量、候选及去重数、夸克失败分类、115/夸克转存数、SmartStrm 触发/重试摘要和最近媒体状态。

## v2.0 能力

### 115 链路（稳定保留）

- 仅访问 Telegram 公开搜索页 `https://t.me/s/<频道>?q=<片名>`，不支持私有频道、邀请链接或登录会话；
- 支持消息内直接的 115 链接，以及 `lsp115` 式「查看资源」跳转到 Telegraph 后的 115 链接；
- 仅接受 `115.com`、`115cdn.com`、`anxia.com` 域名分享；
- 自动处理全部 MoviePilot 待处理订阅；媒体库无缺集明细时按订阅声明范围回退；
- 单字剧名与标题过滤均保持严格匹配；Telegram 候选先按订阅标题初筛、再应用单频道上限；
- 115 的 STRM 生成与 302 播放由「115网盘STRM助手（P115StrmHelper）」链路负责，本插件不介入。

### 夸克链路（v2.0 新增，115 无可用候选时兜底）

```text
订阅缺失
→ Telegram / Telegraph 提取 pan.quark.cn 分享候选（与 115 同一次消息解析）
→ 解析分享 ID / 提取码
→ 运行时复用 QuarkDisk Cookie 获取 stoken
→ 校验分享目录与标题/季/集/扩展名
→ 115 无可用候选时，指定文件转存至夸克个人媒体目录
→ 异步任务等待 + 目标目录二次确认文件真实存在
→ 更新 MoviePilot 订阅缺集/note
→ 触发 SmartStrm 增量生成本地 STRM（失败进入待重试队列）
```

关键约束：

- **115 优先、夸克兜底**：同一集已由 115 链路成功转存（历史记录可见）时，夸克链路直接跳过，绝不双盘重复转存；
- 夸克 Cookie 仅运行时读取 `QuarkDisk` 的 `cookie` 配置，不复制到本插件、不回显、不写日志；
- 夸克远端只保存媒体文件；`.strm`、NFO、海报等全部由 SmartStrm 在本地生成，本插件不调用 MoviePilot 远端刮削；
- 提取码、`stoken`、`share_fid_token` 只在运行内存短期保存，不持久化；
- 风控词（频繁/风控/限制/封禁）触发冷却熔断，仅网络瞬态异常重试；
- 转存成功以「目标目录二次确认文件存在」为准，任务提交不算数；
- 转存成功与 STRM 后处理解耦：SmartStrm Webhook 失败只入待重试队列（最多 N 次后停滞告警），**绝不重新发起网盘转存**。

### SmartStrm 联动

- Webhook 地址从 SmartStrm「系统设置-Webhook」获取；本插件采用与 Quark-Auto-Save 相同的调用契约：
  - `GET webhook` 校验连通性；
  - `POST webhook`，`{"event": ..., "data": {"strmtask": "任务名", "savepath": "转存目标目录", "xlist_path_fix": ""}}`；
- `savepath` 只传本次转存成功的目标目录，SmartStrm 仅对该目录做增量 STRM 生成；
- 夸克网盘驱动时无需填写 `xlist_path_fix`；OpenList 驱动时填「挂载路径:夸克根目录」；
- Webhook 地址属敏感凭据：仅存于 MoviePilot 配置，不写入日志、通知或 Git。

## 部署与配置

1. 安装并启用「夸克网盘存储」（`QuarkDisk`）并完成 Cookie 配置（夸克链路运行时复用）；
2. 在「Telegram 公开频道」填写公开频道用户名或链接，每行一个（默认 `QukanMovie` / `lsp115` / `vip115hot`）；
3. 配置独立的 115 与夸克电影/电视剧转存目录；
4. 如需使用 ED2K / 磁力：在公开频道列表添加 `regeng115`，启用「115 ED2K / 磁力离线下载」，先保持测试模式验证候选和目标目录；
5. 配置夸克链路和 SmartStrm 后处理；
6. 保持「测试模式」开启，先点详情页「立即运行一次」，核对日志中的 Telegram 候选、115/夸克分享校验与剧集匹配；
7. 用详情页「验证夸克连通性」「测试 SmartStrm」分别做只读验证；
8. 确认无误后关闭测试模式。

## 操作页面

- **最近运行状态**：展示上一轮脱敏统计与最近媒体状态；不是实时执行进度。
- **立即运行一次**：异步执行一次完整同步（115 优先，夸克兜底）；
- **验证夸克连通性**：只读验证 `QuarkDisk.cookie` 与账号连通性；
- **测试 SmartStrm**：只读 GET Webhook 校验连通性，不触发任务；
- **清理插件日志**：清空本插件日志，不影响主日志与其他插件。

## 敏感信息边界

以下信息不会被本插件打印、记录或提交到仓库：115/夸克 Cookie、MoviePilot API Token、SmartStrm Webhook 完整 URL（日志仅显示主机名）、分享提取码、`stoken`、`share_fid_token`、完整分享 URL。下载历史仅记录分享 ID 与目标目录。
