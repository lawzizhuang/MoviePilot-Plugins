# 115 TG 订阅追更

MoviePilot V2 插件：读取指定的 MoviePilot 订阅，直接检索 Telegram 公开频道中的 115 分享链接，校验分享目录后转存缺失的电影和剧集。

## v1.0 范围

- 仅支持 Telegram 公开频道网页搜索：`https://t.me/s/<频道>?q=<关键词>`；
- 支持消息内直接的 115 链接，以及 `lsp115` 式「查看资源」跳转到 Telegraph 后提取的 115 链接；
- 仅接受 `115.com`、`115cdn.com`、`anxia.com` 域名的分享链接；
- 自动处理全部 MoviePilot 待处理订阅（状态 `N`、`R`），不需要在本插件重复勾选；
- 当媒体库未返回缺集明细但订阅已设定总集数时，按订阅的起止集数回退搜索，避免“媒体库无该剧”导致不搜索；
- 单字剧名会按原始消息标题匹配，避免中文正则归一化误删标题后跳过正确资源；
- 修复 Telegram 搜索页包含封面图片等无闭合标签时丢失前序消息的问题，确保单片与合集消息都能进入 Telegraph 二跳校验；
- Telegram 搜索结果会先按 MoviePilot 订阅标题过滤，再应用单频道上限，避免同年份相近标题挤占正确资源。
- 不依赖 CloudSaver，不支持私有频道、邀请链接或 Telegram 登录会话。

## 夸克阶段 A（v1.2.0）

本版本只新增夸克分享适配与 `QuarkDisk` 连通性验证，**尚未启用 Telegram→夸克自动转存**，不会改变既有 115 流程。

1. 先安装并启用「夸克网盘存储」（`QuarkDisk`），在其中完成 Cookie 配置；
2. 在本插件勾选「验证 QuarkDisk 夸克连通性」并保存；
3. 点击详情页「验证夸克连通性」，预期日志显示“已复用夸克网盘存储（QuarkDisk）的 Cookie 配置”和“夸克登录验证成功”。

该验证仅调用账号连通性接口：不读取 Telegram 夸克分享、不创建目录、不保存文件。Cookie、分享提取码与临时 `stoken` 均不会写入本插件配置、日志或通知。

后续夸克转存将保持：夸克远端仅保存媒体文件；由 SmartStrm 在本地生成 STRM、NFO 与图片。

## 115 凭据

默认复用已安装的「115网盘STRM助手」（`P115StrmHelper`）插件保存的 `cookies`，与现有的 115 转存及 STRM 链路使用同一凭据；不会把该值复制到本插件配置中，也不会在页面展示或写日志。

如有需要，可在「115 凭据来源」切换为复用「115网盘储存」（`P115Disk`）的 `cookie`，或切换为「本插件独立 Cookie」。三种来源互斥。

## 首次使用

1. 确认「115网盘STRM助手」（`P115StrmHelper`）已经配置有效 Cookie（默认复用）；如有需要可切换至 P115Disk 或独立 Cookie；
2. 配置独立的电影/电视剧测试转存目录；
3. 在「Telegram 公开频道」填写公开频道用户名或链接，每行一个；
4. 保持「测试模式」开启；插件会自动处理全部 MoviePilot 待处理订阅；
5. 打开插件详情页，点击「立即运行一次」，检查插件日志中的消息搜索、115 分享目录和剧集匹配情况；
6. 确认无误后再关闭测试模式。

## 操作页面

点击插件卡片可进入详情页：

- **立即运行一次**：异步触发一次同步；正在执行或已排队时拒绝重复触发；
- **验证夸克连通性**：仅验证是否能运行时复用 `QuarkDisk.cookie`；不会读取分享、创建目录或转存文件；
- **清理插件日志**：清空当前 `p115tgsub` 日志并删除滚动日志，不影响 MoviePilot 主日志、其他插件日志或转存历史。
