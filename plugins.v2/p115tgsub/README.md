# 115 TG 订阅追更

MoviePilot V2 插件：读取指定的 MoviePilot 订阅，直接检索 Telegram 公开频道中的 115 分享链接，校验分享目录后转存缺失的电影和剧集。

## v1.0 范围

- 仅支持 Telegram 公开频道网页搜索：`https://t.me/s/<频道>?q=<关键词>`；
- 支持消息内直接的 115 链接，以及 `lsp115` 式「查看资源」跳转到 Telegraph 后提取的 115 链接；
- 仅接受 `115.com`、`115cdn.com`、`anxia.com` 域名的分享链接；
- 自动处理全部 MoviePilot 待处理订阅（状态 `N`、`R`），不需要在本插件重复勾选；
- 当媒体库未返回缺集明细但订阅已设定总集数时，按订阅的起止集数回退搜索，避免“媒体库无该剧”导致不搜索；
- 单字剧名会按原始消息标题匹配，避免中文正则归一化误删标题后跳过正确资源；
- 不依赖 CloudSaver，不支持夸克、私有频道、邀请链接或 Telegram 登录会话。

## 115 凭据

默认复用已安装的「115网盘储存」（`P115Disk`）插件保存的 `cookie`，不会把该值复制到本插件配置中，也不会在页面展示或写日志。

若未使用 `P115Disk`，可将「115 凭据来源」切换为「本插件独立 Cookie」后，再在本插件填写 Cookie。两种来源二选一。

## 首次使用

1. 确认「115网盘储存」（`P115Disk`）已经配置有效 Cookie（默认复用）；若选择独立模式，则配置本插件的 115 Cookie；
2. 配置独立的电影/电视剧测试转存目录；
3. 在「Telegram 公开频道」填写公开频道用户名或链接，每行一个；
4. 保持「测试模式」开启；插件会自动处理全部 MoviePilot 待处理订阅；
5. 打开插件详情页，点击「立即运行一次」，检查插件日志中的消息搜索、115 分享目录和剧集匹配情况；
6. 确认无误后再关闭测试模式。

## 操作页面

点击插件卡片可进入详情页：

- **立即运行一次**：异步触发一次同步；正在执行或已排队时拒绝重复触发；
- **清理插件日志**：清空当前 `p115tgsub` 日志并删除滚动日志，不影响 MoviePilot 主日志、其他插件日志或转存历史。

```text
QukanMovie

```
