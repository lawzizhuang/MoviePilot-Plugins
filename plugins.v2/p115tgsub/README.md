# 115 TG 订阅追更

MoviePilot V2 插件：读取指定的 MoviePilot 订阅，直接检索 Telegram 公开频道中的 115 分享链接，校验分享目录后转存缺失的电影和剧集。

## v1.0 范围

- 仅支持 Telegram 公开频道网页搜索：`https://t.me/s/<频道>?q=<关键词>`；
- 支持消息内直接的 115 链接，以及 `lsp115` 式「查看资源」跳转到 Telegraph 后提取的 115 链接；
- 仅接受 `115.com`、`115cdn.com`、`anxia.com` 域名的分享链接；
- 复用 115 分享目录校验、剧集缺集匹配、批量转存和 MoviePilot 订阅完成逻辑；
- 不依赖 CloudSaver，不支持夸克、私有频道、邀请链接或 Telegram 登录会话。

## 首次使用

1. 配置 115 Cookie、独立的电影/电视剧测试转存目录；
2. 在「Telegram 公开频道」填写公开频道用户名或链接，每行一个；
3. 指定一部测试订阅；v1.0 默认只处理明确勾选的订阅；
4. 先点「立即运行一次」，检查日志中消息搜索、115 分享目录和剧集匹配情况；
5. 确认无误后再增加订阅范围。

## 默认频道样例

```text
QukanMovie
lsp115
vip115hot
```

`lsp115` 的 Telegraph 页面可能只提供 ED2K 或其他网盘链接；没有有效 115 分享链接时会被安全跳过。
